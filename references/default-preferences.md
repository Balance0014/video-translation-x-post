# Video translation preferences

Edit this local file after the first run. A user's direct request always wins.

- Target language: natural, accurate Chinese.
- Existing English captions: keep readable; put Chinese below. If absent, use Chinese alone.
- Subtitle design: broadcast style, no large solid black bar, no important visual obstruction.
- Watermark: ask for the preferred wording if the request does not specify one; never assume this package's author's handle.
- Speed: preserve source speed unless the user requests a change. At 1.2×, use smooth output-frame sampling rather than extra destructive frame dropping.
- Mirror: only if requested and visible writing will not become reversed.
- X post: hook with the specific story; distinguish a speaker's prediction from fact; attribute source when known.
- Delivery location: use the user's requested path, or ask when unclear.
